## 一、论文定位

### 1.1 拟定标题

**英文：** JIT: Bootstrapping and Exploring Empirical Jumping Envelopes for a Bicycle–Pendulum Robot

**中文：** JIT：自行车摆系统的跳跃引导学习与经验能力包线探索

### 1.2 核心研究问题

> 在固定机器人模型、工况和地面跳跃起点下，如何从稀缺的成功经验出发，以有限交互预算，发现具有真实前向到达和成功续接见证的经验跳跃能力包线？

### 1.3 核心叙事

系统需要持续维持动态平衡，并在有限起跳窗口内协调车体、轮驱动与摆动机构。训练早期的失败可能发生在有效起跳之前，使腾空和落地阶段难以获得充分训练。

JIT 首先通过上升与下降阶段的策略获得局部状态与续接数据，经价值加权形成初始训练 Tube0，再训练出能够完成完整跳跃的种子策略 π0。随后，以 π0 的真实成功轨迹作为纵向探索坐标，通过具有前向来源链的真实动力学扰动和准确状态续接评价，逐步发现周边经验能力支持。多个冻结策略作为互补探针参与前向探索和续接评价，已发现的支持进一步帮助训练新探针。

研究重点从“获得一种成功跳跃行为”推进到“发现并解释固定条件下更广的经验跳跃能力支持”。

### 1.4 已确认的研究选择

| 项目 | 已确认的定义 |
| --- | --- |
| 首要目标 | 发现并扩张固定模型、固定工况下的经验跳跃能力包线 |
| 任务起点 | x=2.5 m 的声明地面准备状态，包含姿态、速度等完整状态 |
| 研究范围 | 起跳前短距离运动、起跳、腾空和首次有效落地 |
| 前向证据 | 从声明起点经真实动力学到达，或继承有效祖先来源链后继续真实动力学演化 |
| 续接准入 | 至少一个声明的评价策略从同一个准确状态完成首次有效落地 |
| 证据强度 | 成功续接见证；不直接解释为可靠成功概率 |
| 策略组织 | 保留互补冻结策略，允许集合逐步扩充 |
| 策略用途 | 同时参与前向探索和续接评价 |
| centerline | 固定的真实轨迹纵向坐标，用于组织探索和比较 |
| 单 Actor | 独立评价其实现范围，不要求覆盖整个累计 Tube |
| 失败解释 | 当前探针尚未找到成功续接，不等于物理不可行 |

这些是新设计方向，不表示历史固定 proposer/evaluator 协议已经按此执行。历史结果保留原有模型、策略集合、终点及数据角色含义。

## 二、正文大纲

### 1. Introduction：为什么需要研究跳跃能力包线

依次展开四层逻辑：

1. **任务困难。**自行车摆系统需要动态平衡与跳跃动作协调；在当前任务条件下，有效起跳机会有限，早期失败可能阻碍后续阶段学习。
2. **成功种子难以获得。**完整任务训练可能缺乏足够的腾空与落地经验，需要分阶段支持来启动学习。
3. **成功策略不足以描述能力。**π0 展示了一种成功行为，但其轨迹不能说明周围哪些位置、速度和姿态状态仍可被到达并继续完成落地。
4. **提出 JIT。**结合分阶段支持引导、纵向组织的真实动力学探索、准确状态续接评价及互补策略探针，构建经验跳跃包线。

贡献集中为两项：

- 一套从分阶段支持引导到经验包线探索的完整方法。
- 对固定模型与工况下的探索效率、物理覆盖和策略互补性的受控实验分析。

写作边界：

- 不将“首次让自行车跳跃”作为未经查证的创新性主张。
- 不将“动作时间短”直接等同于“训练效率低”；用阶段访问和学习曲线验证具体机制。
- “不能停下来思考”改写为声明条件下的动态平衡需求与有限起跳机会。
- “建模困难”具体解释为动力学与接触切换耦合，以及直接求解全程规划或能力边界的困难；不声称完全没有模型。

### 2. Related Work：与已有研究的关系

#### 2.1 动态机器人跳跃与自行车控制

介绍已有方法如何学习成功跳跃和特技。JIT 重点研究成功行为周围的经验能力支持，其区别需要落实在探索方法和评价指标上。

应重点对照 Bicycle Acrobatics with Reinforcement Learning 与 LineRides。前者研究自行车特技及行为组合，后者通过空间引导线和关键姿态学习可指令动作。JIT 的 centerline 用于组织探索，不是要求策略跟踪的目标轨迹。

#### 2.2 分阶段学习与重置课程

说明 up/down、Tube0 的作用，以及与 Reverse Curriculum、RFCL、BaRC 等工作的关系。强调训练重置可以帮助学习，但不能单独提供任务起点的前向到达证据。

#### 2.3 可达性、能力地图与包线

说明经验包线与形式化可达集、安全包线和连续可行区域的区别。JIT 保留有限采样下的成功路径见证，不宣称区域内部每个状态均可行，也不宣称已经找到完整物理边界。

### 3. Problem Formulation：任务和经验包线定义

#### 3.1 固定任务条件

声明机器人模型、载荷、环境、动作与执行器限制，以及：

- x=2.5 m 的完整地面准备状态；
- 起跳、上升、下降和首次有效落地的判定；
- 失败条件、评价时长及剩余时间语义；
- 训练、开发比较和最终评价的数据角色。

本文不要求连接到更早的自然 episode 起点，也不把落地后恢复作为当前成功终点。

#### 3.2 科学对象

| 符号 | 含义 |
| --- | --- |
| S_k | 用于训练和重置的状态支持 |
| R̂_k | 具有有效前向来源链的已观测状态集合 |
| T̂_k | 具有前向到达和成功续接见证的经验能力支持 |
| Π_k | 第 k 轮可用的冻结策略探针集合 |

经验 Tube 定义为：

$$
\widehat T_k=\left\{s\in\widehat R_k:\exists\pi\in\Pi_k,\;\operatorname{LandingWitness}(s,\pi)=1\right\}.
$$

其中，LandingWitness 表示在声明条件和时间范围内，从准确状态出发观测到首次有效落地。它不是经过扰动重复试验估计的成功概率。

先在准确状态上确认前向到达和成功续接，再投影到物理单元。不能把同一物理单元内不同状态的两类证据拼成一个完整见证。

#### 3.3 经验支持与单策略实现

单策略的实现范围独立于累计经验 Tube。新策略不能复现某条旧成功路径，不会抹去有效的历史见证。前向策略与续接策略可以不同，但必须在准确状态及必要控制历史上连接。

经验地图区分“已见证成功”“已尝试但未找到成功”“尚未探索”。固定系统的物理极限不会随训练改变；本文的扩张指已发现经验支持的增加。

### 4. Method：JIT 如何获得并扩张经验支持

#### 4.1 分阶段支持引导：up/down → Tube0 → π0

说明上升和下降策略如何分别获得训练经验、阶段间状态如何捕获与恢复、如何按既定标准筛选初始支持，以及如何训练得到完整跳跃策略 π0。

初始训练支持 S_0 不自动具有经验包线资格。π0 从声明地面起点出发的真实完整 rollout 开始提供前向来源证据。阶段引导的收益需要实验验证，并计入专家获得成本。

#### 4.2 成功轨迹的纵向组织

从 π0 的真实成功轨迹提取 centerline，按 x=2.5, 2.6, 2.7, … 至首次落地组织切片，并说明切片、运动阶段和祖先状态的对应关系。

使用实际捕获的状态，不通过插值生成可达性证据。对同一纵向位置的不同阶段或多次经过，应声明消歧规则。

#### 4.3 具有前向来源链的探索

从声明起点或具有有效来源链的祖先状态出发，选择冻结的前向策略，在指定窗口施加有界控制扰动，通过真实动力学进入候选状态，保存完整状态、策略身份、扰动、时间和祖先关系。

多个策略参与前向探索。恢复祖先状态只继承已有前缀证据，新增证据来自恢复后实际执行的动力学转移。

#### 4.4 成功续接评价与 Tube 更新

对准确候选状态使用冻结策略集合分别评价。至少一个策略完成首次有效落地，就获得成功见证。

- 保留逐策略结果，不能只保存 OR 标签。
- 按固定分辨率统计新增物理支持，同时保存原始准确状态。
- 保留历史见证及其策略集合版本。
- 分别统计新到达状态的成功见证，以及新策略对历史未成功候选的新增续接见证。
- 同一物理单元中的样本可以保留，用于重复评价与局部差异分析；物理去重主要控制新增覆盖计数。

#### 4.5 新策略探针与迭代探索

利用已发现支持训练新的策略探针，再将冻结的新策略用于后续探索和评价。

**待锁定的方法规则：**

1. 下一轮选择哪些训练支持。
2. 如何促进新策略产生互补行为。
3. 新策略加入探针集合的条件。
4. 探索预算在切片、扰动和策略之间如何分配。
5. 累计收益与成本达到什么条件时停止。

不要求新策略替代旧策略或覆盖整个 Tube。这一节必须给出可执行规则，不能只写“训练后继续扩张”。预测器若尚未证明改善探索，就作为辅助诊断，不列为主贡献。

### 5. Experiments：围绕三个问题建立证据

| 研究问题 | 对照设计 | 主要指标 |
| --- | --- | --- |
| 分阶段支持是否帮助获得成功种子？ | 直接完整任务训练，对比分阶段支持引导 | 阶段访问率、达到声明成功水平的交互成本 |
| JIT 是否更有效地发现经验支持？ | π0 单策略探索、固定策略集合均匀探索、JIT 迭代探索 | 同预算新增有效物理单元、重复采样比例 |
| 策略集合是否提供互补能力？ | 单策略与策略集合；固定集合与扩充集合 | 独有成功见证、边际覆盖收益及成本 |

必要的可信度检查：

- 成功路径准确重放。
- 物理分辨率敏感性与分阶段结果。
- 独立重复实验，以及考虑父轨迹相关性的统计。
- 训练、采集、续接评价、开发选择与失败重试的完整成本核算。
- 策略训练和探索不得使用留给最终评价的数据。

机制比较可以共享同一套 bootstrap；报告端到端效率时必须计入 up/down 和 π0 的获得成本。匹配物理覆盖定义和总体任务条件，不能把更多计算或更宽扫描范围直接解释为算法收益。

### 6. Results and Discussion：包线揭示了什么

依次回答：

1. 分阶段支持是否缓解有效训练经验不足。
2. 同预算下，JIT 是否发现更多有效支持。
3. 新支持主要出现在哪些纵向位置与运动阶段。
4. 不同策略贡献了哪些互补区域。
5. 哪些区域多次尝试仍未找到成功，可能的限制因素是什么。
6. 单 Actor 的实现范围与累计 Tube 有多大差距。

不预设截面必然连续变宽；不把无法进一步扩张解释为找到物理极限；不把某策略训练支持上的实现率当作最终完整任务泛化结果。

### 7. Conclusion：准确收束贡献

结论说明如何启动困难任务的成功行为学习、如何构建具有真实动力学来源的经验支持，以及实验实际验证了哪些收益和局限。

结论限定于声明的模型、工况、初始状态、任务终点、探针集合和探索预算。单 Actor 完整覆盖累计 Tube 不作为论文成立条件。

## 四、写作与实验完成顺序

1. 固定任务起点、失败和落地判据，区分训练支持与经验能力支持。
2. 整理 up/down、Tube0、π0 的证据，补阶段访问和学习成本对照。
3. 锁定第4.5节：训练支持选择、互补探针生成、探索分配与停止规则。
4. 验证前向来源链、准确状态恢复、策略身份和续接终点的一致性。
5. 完成同预算探索对照及独立重复，生成覆盖—成本主图。
6. 分析物理截面、策略互补性、分辨率敏感性和未成功区域。
7. 根据实际结果撰写摘要与结论，保留未验证主张的限制。

当前最需要补强的是第4.5节和图4：明确新探针如何产生，并检验迭代探索相对于同预算直接探索的收益。前期 up/down、Tube0、π0 负责解释方法如何启动；后期包线发现的受控结果承担主要贡献。
