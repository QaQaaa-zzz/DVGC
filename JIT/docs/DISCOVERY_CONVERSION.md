# Conversion-first exploration reward

Opt-in `quality_mode=discovery_conversion` preserves historical delayed/current-policy/novelty-only behavior. Each candidate records `pulse_cells`: physical root-geometry cell IDs after each actually applied perturbation step. Normal approach and unperturbed continuation frames do not enter this window statistic. Existing quantization is unchanged; cell novelty is not continuous reachable-volume proof.

At each batch, freeze the current-source visited ledger. Reward initial source failure followed by verified same-context successor success with `conversion` (+2 in the new experiment). Known source successes receive no success bonus. Actual unsuccessful retraining receives `-failure` (−0.5). Direct physical failure during an applied pulse receives `-pulse_failure` (−5), with no novelty bonus. Unknown, unevaluated or unattempted negative outcomes receive no PPO eligibility or synthetic punishment.

For each non-physical-failure eligible candidate, novelty is `novelty_weight * sum(1 / batch_candidate_count(cell) for new unique pulse cells) / number_of_unique_pulse_cells`. This is capped at0.05 with the new configuration. If every pulse-window cell was already in the frozen ledger, subtract `repeat` (0.1). Conversion still dominates this repeat penalty. Update the ledger with all actually observed pulse cells, including failed/unknown outcomes; physical observation is distinct from successful continuation evidence. In the existing current-source iteration, accepted source changes rebuild the source ledger; novelty is policy-relative, not an all-policy lifetime guarantee.

PPO terminal feedback remains attached to the final applied pulse action and propagated through the existing return computation. `verified_conversions`, `source_successes`, `repeated_windows`, positive novelty and repeat components are separately logged. Conversion proves local learning under the successor; promotion/final-policy retention must be reported separately. Rejected successor gains must never be presented as final-policy capability.

Fresh initialization can explicitly declare `explorer_initialization={mode:symmetric, latent_std:0.6}`. The last Actor layer is zeroed; mean0 and equal constant latent standard deviation hold for every input initially. The bounded action is0.25*tanh(Gaussian), symmetric but not uniform. Hidden features remain randomly initialized and the policy becomes state-dependent through learning. Historical explorers are not restored. This guarantees an unbiased initial distribution, not exact sign balance in a finite batch.

A hash-locked `jit_phase_checkpoint_initialization_source_v1` descriptor permits the existing zero-training initializer to accept a Phase U checkpoint. The upstream runtime must match exactly; XML and observation/action identity must agree. Actor, Critic and normalizer hashes are unchanged, a separate `transition_0` copy records zero new transitions, and its receipt names the original Phase checkpoint and original training count. This is an initialization-only binding to the full-task runtime, not completed full-task training or expert switching. Subsequent jump-policy PPO keeps fresh Critic/optimizer as before.
