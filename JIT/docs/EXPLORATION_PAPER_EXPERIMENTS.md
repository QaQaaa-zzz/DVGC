# 经验跳跃包线：已批准的分阶段实验

本文登记本轮实验配置、数据角色、预算和停止条件。旧奖励对照及旧多种子计划保持暂停，旧的2秒成功标签、轨迹和图件保持冻结；它们不能作为新的0.5秒实验结果。本文中的后续阶段是已批准的计划，尚未实现的机制明确标出，不据此宣称实验已经完成。

研究问题是：在相同初始 Actor、物理条件、成功协议和完整交互成本下，学习探索能否比固定随机探索产生更多可接续、可补训学会的真实到达状态；训练所得单个 Actor 是否在独立扰动任务中受益。包线的前缀与续接见证、补训的同状态转换和单 Actor 全程任务成功分别报告。

## 共同协议

- 初始 Actor 为用户指定的 Phase U Actor；新源包装只登记0.5秒运行协议和同一参数身份。新实验不导入历史π1～π6、旧候选池或旧成功支持。模型、载荷、归一化观测、动作顺序、完整固定起点与控制周期保持一致。
- 成功使用`configs/descent_stable_forward_0p5s.json`：接触帧之后连续25个完整控制步稳定前进，dt=0.02秒；不稳定时计数归零。保持速度、姿态、接地和无物理失败条件，不额外要求1米进度。首次接触与成功终点分别记录。
- 所有新臂使用共同`original_all_phases`任务奖励；奖励数值不替代成功/失败终点。探索器奖励单独保存。
- 脉冲为四个合法归一化动作通道上的有界残差，持续3个控制步。事件为起点、离地、顶点、下降接近落地；下降触发的轮胎离地阈值为0.10米。记录每条轨迹的实际事件、触发时刻、请求幅度、有效幅度、限幅、未触发和终点。
- 起始事件从当前完整状态识别，后续事件逐 lane 识别。未到达事件不凭控制步索引假造事件。所有采集及续接的硬时域为400步；未知、非有限状态及冲突保留原始原因。
- 初始支持只能由当前臂的源策略新生成真实 nominal 轨迹及同状态续接验证建立。仅源参数和明确的几何/起点身份可共享；每臂拥有独立轨迹、ledger、候选池、策略、探索器及优化器状态。
- TRAIN指导适应；开发固定面板用于预先声明的保留检查。最终独立测试在全部训练冻结之后才执行，不用于调整奖励、幅度、模型或checkpoint。初态种子不是独立训练种子。

## 首阶段：固定策略的探索机制比较

目的：固定 Actor 及续接评价器，先确认探索器的事件采样、质量反馈、学习更新和完整成本是否具有区分度。此阶段不训练后继跳跃 Actor，不能用它证明外循环补训或最终Actor能力提高。

默认seed=9991501，每臂最多24轮×128候选，每臂实际交互硬上限2,500,000。两臂同源、同seed、相同事件和幅度日程；各自维护独立数据。若实际预算不足以安全启动下一完整子阶段则停止，并报告完成轮数与实际事件分布，不能把未完成轮补成结果。

| 条件 | 学习探索 | 固定随机探索 |
| --- | --- | --- |
| `controller_mode` | `learned_residual` | `fixed_random` |
| 跳跃策略 | 同一冻结初始Actor，`training_mode=fixed_policy` | 同左 |
| 候选质量 | 当前策略单独续接，`quality_mode=current_policy` | 同左 |
| 探索器更新 | 独立残差Actor/Critic PPO | 不执行优化器更新 |
| 探索器回报 | 新颖性0.25，当前成功+1，明确当前失败−1 | 记录相同分项用于对照 |
| 未知结果 | 不作为失败，不进入PPO样本 | 同左 |

默认八轮组合为`(start,.10),(liftoff,.10),(apex,.10),(descent,.10),(start,.15),(liftoff,.15),(apex,.15),(descent,.15)`，重复三次。所有通道使用同幅度上限。相位与幅度完全交叉；不能把两个独立短周期相同索引相乘造成相位/幅度混淆。

探索器PPO沿用已有学习分支：lr=3e−5、epochs=4、minibatch=128、clip=0.2、target_kl=0.01、gamma=lambda=1、value coefficient=0.5、entropy coefficient=0.001、max gradient norm=1。保留更新前后KL、实际接受更新数及损失、奖励分项、梯度、学习率和checkpoint；target_kl字段本身不是硬拒绝更新的证据。

准备接口只做CPU身份验证和文件生成：

```bash
  --task-template-bank <declared-task-identity-bank.json> \
  --jump-start-state-sha256 <declared-complete-fixed-start-sha256> \
  --output <fresh-experiment-directory> --seed 9991501 \
  --num-envs 128 --rounds 24 --amplitudes .10 .15 \
  --max-actual-interactions 2500000 --recovery-seconds .5
```

`--task-template-bank`只提供XML、完整起点契约、中心线和分辨率四项身份，不导入成员、支持、标签或成本。新bank重新登记0.5秒端点配置哈希。源策略的实际down_config须与声明的连续恢复时间一致；旧2秒源直接提交会被拒绝。

输出包括独立的`learned/initial_bank.json`、`fixed_random/initial_bank.json`与各自`spec.json`，顺序执行的`plan.json`、预算账本和`ACTIVE_RUN.json`。输入/源码锁在准备时生成，因此应在实现全部完成后准备；锁定后代码改变须建立新声明。准备不启动仿真。

CPU顶层执行器可以先启动，各GPU子任务通过`gpu_idle`查询计算进程，最多等待72小时。不读取其他项目的源码/结果，不终止其他任务。执行器不自动重试。启动或重启执行器时，必须同时启动并核验`cli/watch_run_errors.py --active-run <root>/ACTIVE_RUN.json --state-dir <root>/notifications`的心跳和通知服务；错误与整个顶层计划完成分别通知，不因某个子阶段完成提前弹出总体完成。

## 主实验：B/C/D独立训练谱系

主实验每臂3个独立训练seed，每条谱系最多6,000,000实际交互、最多60轮，每轮128候选，单次补训128,000 PPO步。三臂初始Actor、观测、物理、成功协议和任务奖励一致；按完整成本截面比较，不能令有补训的臂只统计采集成本。

| 臂 | 目的与训练支持 |
| --- | --- |
| B：继续PPO | 仅初始Tube支持继续训练，禁止加入新扰动候选；检验额外优化预算能否解释收益 |
| C：固定随机＋补训 | 均匀固定随机动作残差产生新候选，当前策略续接并按共同条件触发补训；探索器不学习 |
| D：学习探索＋补训 | 学习残差产生候选，保留延迟质量反馈，探索与后继策略训练构成闭环 |

C/D当前策略单独产生前缀并验证，不借用历史策略库见证。PPO reset保持20%完整固定起点＋80%快照，快照按相位平衡；某相位存在pending时，该相位内部50% pending、50%旧成功支持。探索器延迟反馈为新颖性0.25、成功见证+1、补训后明确失败−1；没有尝试补训且仍未解决的候选不能冒充补训失败。

主实验提议的新增保留门槛为：相对冻结初始π0开发面板成功率下降不超过1个百分点，当前策略旧面板保留至少95%。初始/当前面板分别冻结并保留分母，不能把16状态面板称全Tube保证。新增PPO学习率约束为初始/上限3e−5、下限1e−5、target KL=0.01，并拟实施更新后超阈值硬拒绝。**这些主实验新门槛及硬拒绝机制仍需实现和行为验证，首阶段准备器不会宣称已提供。** 后续正式启动声明须给出精确阈值、面板规模、seed和失败后的停止规则。

## 消融

两项消融各3个独立训练seed，每条2,000,000交互，除声明的反馈变化外与D一致。它们与D在2,000,000相同累计成本的冻结结果比较，不能用D最终6,000,000结果作为相同预算对照。

| 消融 | 唯一预期变化 |
| --- | --- |
| novelty_only | 探索器只用新颖性，质量权重为零；补训、保留与评价预算仍一致 |
| current_policy | 探索器使用候选初次被当前Actor续接的立即质量反馈；仍执行与D相同的后继补训和保留流程 |

第二项用于区分延迟“补训后可学会”反馈与当前可续接反馈；不能通过取消其补训预算改变问题。两项消融的正式配置与实现尚待首阶段完成后冻结。

## 冻结评价与允许结论

最终评价10个唯一Actor：共同初始Actor＋B/C/D各3个seed的预先声明最终Actor。每个Actor的10,000条独立扰动轨迹来自5个幅度`[.05,.10,.15,.20,.25]`×4个事件×每组合500条，统一最长400控制步。先锁定精确随机采样、episode身份和事件条件，全部训练/选择结束后才运行。若checkpoint因保留门槛没有晋升，按声明选取最后已接受Actor并如实说明，不能事后挑最优测试checkpoint。

另固定1,000个独立同状态/完整上下文交接样本，对10个Actor各续接400步，最多4,000,000交互；用于区分新到达空间与接续能力。按初始状态生成方案、事件和数据角色登记来源，不能把训练pending样本当独立测试样本。若原始状态未被真实前缀到达，则不能据此增加包线见证。

延长检查预先选定每Actor1,000条轨迹，在0.5秒成功记录之后最多再模拟75步；额外上限750,000。原成功终点和这段后续稳定表现分开保存，后续失败不静默修改此前冻结成功定义，也不能把0.5秒成功直接称长时稳定。

只有独立重复、等总成本对照和冻结最终评价完成后，才讨论探索效率、可学习候选转换和单Actor任务能力。有限点集、分辨率单元、存活或短时稳定均不构成完整物理可达域、形式稳定性证明或实车验证。
