# Reproducible paper data

These are read-only derivatives of completed local DVGC/JIT artifacts. They contain no model, executable policy, raw simulator snapshot, or private credential. Every selected source field and every original source SHA-256 is recorded under `sources/`. Original run files are unchanged.

Run with standard Python only, from any checkout:

```bash
python JIT/docs/paper/data/rebuild.py --check
```

This verifies snapshot hashes, recomputes the tables, checks cost sums and candidate continuity, and compares generated bytes with the committed files. It does not need `runs/`, JAX, MuJoCo, GPU access, or Git. Omit `--check` to regenerate the derived files. `--capture` is a separate explicit operation that reads the original local artifacts and refreshes snapshots; it is not needed to reproduce this dataset.

`evidence.json` is the machine-readable entry point: schema, capture date, audit checkout HEAD/ref, table grain, row counts, source paths/hashes, interaction totals, and claim limitations. Audit HEAD identifies the checkout used to extract evidence; it is not a claim that every historical experiment used that revision. `sources/manifest.json` binds each compact snapshot to its original file and documents its projection. Snapshot files are exact selected fields, not complete replacements for the original raw evidence.

## Tables and plotting fields

### `delayed_rounds.csv`

Four rows: round index 0/1 × `learned_residual`/`fixed_random`. Pool counts are cumulative within each arm; exploration counts and costs are incremental for that round.

| Fields | Meaning |
| --- | --- |
| `round_index`, `arm`, `source_proposer` | Round, exploration controller, and shared frozen base-policy identity. |
| `exploration_seed`, `shared_policy_training_seed` | Recorded seeds. They do not designate independent experimental repetitions. |
| `candidate_contexts`, `newly_acquired_contexts` | Distinct full-context pool keys; cumulative and first discovered in this round. |
| `witnessed_contexts`, `verified_root_cells` | Successful full-context candidates versus deduplicated witnessed physical cells. These are different grains. |
| `pending_contexts`, `pending_root_cells` | Retained candidates without a witness and their deduplicated cells. Pending does not imply physical impossibility. |
| `previous_bank_no_witness_to_witness`, `unknown_to_witness` | Before/after training changes on the same keys. Both kinds are zero in both arms and both rounds. |
| `forward_scheduled_interactions`, `forward_active_interactions`, `forward_padding_interactions` | Charged slots, useful active physics steps, and inactive slots. Includes initial/final diagnostics. Active + padding = scheduled. |
| `training_arrival_credit`, `final_diagnostic_arrival_credit` | Provisional arrival novelty credit, not witness counts. |
| `initial_baseline_cells` | Actual initial dense base-policy arrival ledger size for that round. Not the historical 9,296-cell campaign baseline. |
| `residual_optimizer_updates`, `training_episodes`, `training_landing_successes` | The four residual-collection batches, including random control's zero optimizer updates. |
| `final_diagnostic_episodes`, `final_diagnostic_successes`, `final_diagnostic_deterministic` | Complete final diagnostic counts and execution mode. Learned is deterministic; random is stochastic, so these are not a matched-mode success-rate comparison. |
| `independent_repetitions` | False: shared ancestry, a single adaptive pipeline, fixed initial conditions. |
| `source_ids` | Semicolon-separated keys in `evidence.json` → `sources`. |

Only learned-arm pending candidates train the shared next policy. Random is a conditional exploration control, not an independently trained end-to-end baseline. Latest results combine the immutable original reuse run and the separate completed continuation. The original gate-timeout error record is retained.

### `cost_breakdown.csv`

One additive component per `scope`, `stage`, optional `round_index`, and optional `arm`. `charged_interactions` is the value to sum **within one scope**. `maximum_interactions` is a declared ceiling where separately available; blank means not separately assigned/available, not zero. `active_interactions` and `padding_interactions` are supplied only where the source separately measured them.

`accounting=inherited_reused_once` identifies first-round learned arrivals that were acquired by the stopped predecessor and reused by the replacement run; they appear exactly once. `failed_reservation` preserves the charge of an unsuccessful engineering preflight. `scope` separates historical new work, inherited recorded work, early/late checkpoint pipelines, delayed pilot, off-target full-action engineering, and corrected residual engineering.

Do not sum checkpoint-prefix surcharges in the comparison table into these totals. These scopes do not collectively claim complete project lifecycle accounting: older bootstrap, unlisted engineering runs, and other historical experiments are excluded.

### `historical_campaign.csv` and `historical_proposers.csv`

`historical_campaign.csv` includes the inherited starting point (`round_index=-1`) and both completed production rounds. Plot `cumulative_new_interactions` against `cumulative_root_cells`; the x coordinate excludes inherited costs. `new_root_cells` is the incremental campaign union, and `ppo_interactions` is training in that round. `new_candidates` counts new acquisition candidates, not total cumulative plotted rows.

`historical_proposers.csv` retains all 13 proposer-round rows. Its `candidates`, `witnessed`, `root_cells`, and `novel_vs_round_start` fields have the original cumulative scope. Proposers have different schedules and inherited panels; these rows are not a controlled ranking. Historical landing/failure conflicts remain in their original label semantics.

### `checkpoint_comparison.csv`

Eight rows: four arms in each of `experiment=early` and `experiment=late`. Original full-schedule metrics are retained, including candidate negatives/unknowns, `clean_forward_landings`, `trajectory_count`, `novel_root_cells`, `charged_interactions`, `training_surcharge`, and `training_inclusive_interactions`.

For the common-exploration-cost view, plot `common_budget_novel_root_cells` against `common_exploration_budget`; `common_budget_spent` records the actual complete-candidate prefix affordable at that ceiling. These are conservative **offline declared-order truncations**, not new live fixed-budget experiments. The `common_training_inclusive_*` fields and `common_budget_below_training_surcharge` retain the negative training-cost result. `baseline_root_cells` names the size of the frozen historical novelty exclusion. Early and late runs are separate fresh training invocations, not an optimizer continuation.

### `geometry_points.csv`

All 10,464 original rows from `all_proposers_v1/round_001/figures/all_points.csv`, in original order; no row or label filtering. The original-to-output column mapping is identity and recorded in the source manifest. `sources/historical_geometry.csv.gz` is a losslessly compressed copy of these selected columns, allowing independent offline reconstruction.

Coordinates: root positions in metres, root translational velocities in m/s, roll/pitch in degrees. `phase` is upstream/downstream. `proposer` supports colour/faceting; `witnessed` retains the historical boolean. `key`, `state_sha256`, `snapshot_context_sha256`, and `root_cell` retain identity and deduplication information. Repeated physical cells and unwitnessed rows are deliberately present. `physical_resolution` is preserved in `sources/historical_geometry_manifest.json`; it is distinct from display slice spacing.

Plot separate phase projections, retaining unwitnessed points and visible gaps. Positions and velocities do not identify a complete closed-loop context. Do not connect slice minima into a trajectory, fill a reachability hull, claim a continuous feasible set, or silently apply later quarantine labels.

## Verification boundary

The rebuild asserts that the historical projected witnessed-cell union agrees with the campaign summary, source candidate keys/cells persist across delayed reevaluation, the latest summary agrees with recomputed pool counts, each completed cost component sums correctly, and charged forward slots equal active plus padding. It preserves all arms and zero/negative outcomes. This is a deterministic artifact consistency check, not simulator replay, new scientific evaluation, or independent certification of historical labels. None of these data opens final TEST.
